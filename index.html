    Ajouter un Pi

    Le nom choisi dans la console (par exemple controltower), ou son adresse IP (par exemple 192.168.1.196), donnée par la liste des appareils de votre box.

    Chercher à la maison

    L'application essaie les noms qu'elle connaît : ceux de votre liste et pi-appliance.local. Un téléphone ne peut pas lister les appareils du réseau : un Pi dont elle ne connaît pas le nom ne sera pas trouvé.

    • Pour un nouveau Pi, utilisez le code QR de sa console, ou cherchez-le dans la liste des appareils de votre box.
    • Un Pi n'est trouvé que si vous avez déjà accepté l'alerte du certificat de sa console dans ce navigateur. Sinon, il semble absent même s'il est là.
    • Chrome va vous demander d'autoriser l'accès aux appareils de votre réseau : acceptez-le, sinon rien ne pourra être trouvé.

      Ajouter ce Pi ?

      Mettre l'application sur l'écran d'accueil

      L'application est déjà installée sur ce téléphone.

      Sur Android, avec Chrome : touchez le bouton ci-dessous, ou le menu ⋮ puis « Ajouter à l'écran d'accueil ».

      Sur Android, avec Firefox : touchez le menu ⋮ puis « Ajouter à l'écran d'accueil » (ou « Installer »).

      Sur iPhone, avec Safari : touchez « Partager » (le carré avec une flèche), puis « Sur l'écran d'accueil ».
