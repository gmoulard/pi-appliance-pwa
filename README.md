# pi-appliance — application mobile

Application web installable (PWA) qui accompagne [pi-appliance](https://github.com/gmoulard/pi-appliance) : la documentation lisible sur le téléphone même sans réseau, et un lien direct vers chacun de ses Raspberry Pi.

Projet en cours de conception : voir la [spécification](docs/specification.md) et le [TODO](docs/TODO.md). Publication prévue à l'adresse `https://app.pi-appliance.com`.
